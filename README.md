# Bistro System (Group 4)

This repository contains the semester project for the **Bistro Restaurant Management System**, developed as part of the Software Engineering course **61756 – Methods for Software Development**.

The project simulates a full restaurant management platform that allows restaurant staff and customers to manage reservations, tables, and restaurant operations through a client-server architecture.

---

## Project Overview

The **Bistro Restaurant Management System** is designed to support the daily operations of a restaurant.  
The system allows restaurant staff to manage reservations, track customers, and organize restaurant tables efficiently.

The project was developed using an object-oriented approach and includes a client-server architecture connected to a relational database.

---

## Main Features

- User management (customers, staff members, administrators)
- Table reservation management
- Client-Server communication between application components
- Database integration for persistent data storage
- Structured object-oriented system design
- Modular architecture for scalability and maintainability

---

## Technologies

- **Java**
- **MySQL**
- **Object-Oriented Programming (OOP)**
- **Client-Server Architecture**
- **SQL Databases**

---

## System Architecture

The system follows a **Client-Server architecture**, where:

- The **client** handles user interaction and interface logic.
- The **server** processes requests and communicates with the database.
- The **database** stores users, reservations, and restaurant data.

This architecture separates responsibilities between system layers and allows better scalability and maintainability.
